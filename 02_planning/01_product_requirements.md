## User and goal

**Who will use this program?**
The Phone Customer
**What problem will it help them solve?**
Amount of data usage and how much they owe with data they spent.
## Requirements

Write each requirement as “The program must…” in your own words. Cover the inputs, processing, and output described in the problem statement. Include the usage categories and input assumptions. Make each statement specific enough to check. Add numbered items as needed.

1. The program must: ask the user for the amount of data used in GB and the base plan cost.
2. The program must: accept whole or decimal numbers, and can assume all input is numeric.
3. The program must: treat 10 GB or less as within the allowance and charge only the base plan cost.
4. The program must: add $2 to the bill for each GB used over 10 GB.
5. The program must: label usage up to 5 GB over the limit as moderate and more than 5 GB over as high.
6. The program must: tell customers within the allowance that they stayed within their data limit.
7. The program must: tell customers over the allowance how many GB over they went and whether it was moderate or high.
8. The program must: display the total bill in dollars with two decimal places.
